# Examples

| file | what |
|---|---|
| `get_sample_data.sh` | downloads public samples: abdominal CT (TotalSegmentator test file), MNI152 T1 template, NIH chest X-ray |
| `python_api.py` | using open-med-mcp from Python without an agent (registry, job contract, viewer) |
| `agent_session.md` | an annotated end-to-end session (tool calls and what the agent saw) |
| `custom_guideline.md` | a workspace guideline that overrides a preset |
| `mcp_configs/` | client configuration snippets |
