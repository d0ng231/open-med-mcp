# Tool reference

Generated by `docs/generate_tools_md.py` from the running server. Paths are resolved against the workspace; all coordinates are native voxel indices (see [coordinates.md](coordinates.md)).

## Tools

### `list_workspace`

List images, masks, DICOM folders and other files in the workspace (paths are relative to it).

| parameter | type | default | description |
|---|---|---|---|
| `subdir` | string | `` | Sub-directory of the workspace to list ('' = workspace root) |
| `pattern` | string | `*` | Glob pattern, e.g. '*.nii.gz' |
| `recursive` | boolean | `False` |  |
| `max_items` | integer | `300` |  |

*Read-only.*

### `inspect_image`

Describe an image: geometry (size, spacing, orientation, planes), intensity statistics,
        modality guess and metadata. Call this first for every new image; all coordinates in later
        calls refer to the reported native voxel index space.

| parameter | type | default | description |
|---|---|---|---|
| `path` | string | *required* | Image file (NIfTI, NRRD, MetaImage, PNG/JPEG/TIFF, DICOM file) or a DICOM series folder |
| `preview` | boolean | `True` | Return a preview PNG of the middle slice |
| `window` | any | `None` | Preview window: preset name, {center,width}, [lower, upper] or 'auto' |

*Read-only.*

### `convert_image`

Convert an image (e.g. a DICOM series folder) to NIfTI (or another format by extension).

| parameter | type | default | description |
|---|---|---|---|
| `path` | string | *required* | Source image or DICOM series folder |
| `output` | string | `None` | Destination file; default <omm_outputs>/converted/<name>.nii.gz |

### `list_models`

List available models (segmentation, classification, preprocessing) with tasks, modalities
        and prompt types. Use describe_model for parameters.

| parameter | type | default | description |
|---|---|---|---|
| `task` | string | `None` | Filter by task name (e.g. segment, total, lobes) |
| `modality` | string | `None` | Filter by modality (CT, MR, XR, US, RGB ...) |
| `category` | string | `None` | segmentation | classification | preprocessing | detection |
| `check_backends` | boolean | `False` | Also report which execution backends can run each model (slower) |

*Read-only.*

### `describe_model`

Full description of a model: tasks, parameters (JSON schema), outputs, weights status,
        backends, license and citation.

| parameter | type | default | description |
|---|---|---|---|
| `name` | string | *required* | Model name from list_models |

*Read-only.*

### `download_weights`

Download a model's weights into the local weights directory (needed once per machine).
        Models that fetch their own weights on first run report that instead.

| parameter | type | default | description |
|---|---|---|---|
| `model` | string | *required* |  |
| `weights` | array of string | `None` | Weight ids to fetch (default: all declared) |

### `run_model`

Run any model of the zoo through the job contract (local / Docker / Apptainer backend chosen
        automatically). Returns output paths, label names, statistics, inlined JSON results and a preview.

| parameter | type | default | description |
|---|---|---|---|
| `model` | string | *required* | Model name, e.g. totalsegmentator, lungmask, hdbet, synthstrip, nnunet, monai, classical |
| `inputs` | object | *required* | Input files by role, usually {'image': 'path'} (some tasks need none) |
| `task` | string | `None` | Task name (see describe_model); default = the model's default task |
| `params` | object | `None` | Model parameters (see describe_model params_schema) |
| `output` | string | `None` | Copy the main mask output to this path |
| `preview` | boolean | `True` | Return a three-plane preview PNG when the result is a mask |

### `segment`

Segment a structure. For promptable models give at least one box or point; the result is a
        label map (label = object_id), statistics and a preview. Look at the preview, then refine.

| parameter | type | default | description |
|---|---|---|---|
| `image` | string | *required* | Image path (2D or 3D) |
| `model` | string | `medsam2` | Promptable model (medsam2, sam2) or automatic model (totalsegmentator, lungmask, classical ...) |
| `prompts` | array of Prompt | `None` | Point/box prompts in native voxel coordinates (required for promptable models) |
| `plane` | `axial` \| `coronal` \| `sagittal` | `axial` | 3D: plane along which 2D prompts are placed and the mask is propagated |
| `params` | object | `None` | Extra model parameters, e.g. {'variant': 'medsam2_ct_lesion', 'window': 'lung', 'max_slices': 20} |
| `task` | string | `None` | Task for automatic models (e.g. 'threshold' for classical, 'lobes' for lungmask) |
| `output` | string | `None` | Copy the mask to this path |
| `preview` | boolean | `True` |  |

### `classify_image`

Run a classification model and return per-class probabilities (plus a bar chart).

| parameter | type | default | description |
|---|---|---|---|
| `image` | string | *required* | Image path (e.g. a chest radiograph) |
| `model` | string | `torchxrayvision` | Classification model, e.g. torchxrayvision |
| `params` | object | `None` |  |
| `preview` | boolean | `True` | Return a bar chart of the probabilities |

### `run_batch`

Run one model over many images (cohort processing). Returns a per-case table with status,
        run directory, foreground volume and per-label volumes, and writes it as CSV + JSON.

| parameter | type | default | description |
|---|---|---|---|
| `model` | string | *required* |  |
| `images` | array of string | `None` | Explicit image paths |
| `pattern` | string | `None` | Glob pattern relative to the workspace, e.g. 'cohort/*.nii.gz' |
| `task` | string | `None` |  |
| `params` | object | `None` |  |
| `output_dir` | string | `None` | Copy each mask here as <image name>_<model>.nii.gz |
| `max_cases` | integer | `500` |  |
| `continue_on_error` | boolean | `True` |  |

### `mask_stats`

Per-label voxel counts, volumes (mL), bounding boxes, centroids, connected components,
        slice ranges and (with image) intensity statistics.

| parameter | type | default | description |
|---|---|---|---|
| `mask` | string | *required* | Label map path |
| `image` | string | `None` | Image with the same geometry, for intensity statistics inside each label |
| `labels` | array of integer | `None` | Restrict to these label ids |

*Read-only.*

### `postprocess_mask`

Clean up a label map with morphological/connected-component operations.

| parameter | type | default | description |
|---|---|---|---|
| `mask` | string | *required* |  |
| `ops` | array of object \| string | *required* | Operations in order, e.g. ['largest_component', 'fill_holes', {'op': 'remove_small', 'min_mm3': 100}, {'op': 'keep_labels', 'labels': [5]}, {'op': 'close', 'radius': 1}, 'binarize'] |
| `output` | string | `None` | Destination path (default: next to the input with a _pp suffix) |
| `image` | string | `None` | Image for a preview of the result |
| `preview` | boolean | `False` |  |

### `compare_masks`

Dice, IoU, precision/recall, volume difference and surface distances between two label maps,
        with an optional contour overlay of both.

| parameter | type | default | description |
|---|---|---|---|
| `mask_a` | string | *required* | Prediction / first mask |
| `mask_b` | string | *required* | Reference / second mask |
| `image` | string | `None` | Image for the visual comparison |
| `labels` | array of integer | `None` |  |
| `surface_metrics` | boolean | `True` | Compute Hausdorff/HD95/ASSD (slower on large masks) |
| `preview` | boolean | `True` |  |

*Read-only.*

### `mask_to_prompts`

Turn any mask (coarse threshold result, another model's output) into box/point prompts
        for a promptable model - the usual way to chain automatic and promptable models.

| parameter | type | default | description |
|---|---|---|---|
| `mask` | string | *required* |  |
| `plane` | `axial` \| `coronal` \| `sagittal` | `axial` |  |
| `label` | integer | `None` | Use only this label (default: all foreground) |
| `slice_index` | integer \| string | `auto` | Slice to place the prompt on, or 'auto' = slice with the largest area |
| `margin` | integer | `2` | Box margin in voxels |

*Read-only.*

### `resample_image`

Resample an image or mask to a new spacing, by a factor, or onto a reference grid
        (e.g. bring a mask into the geometry of another image before compare_masks).

| parameter | type | default | description |
|---|---|---|---|
| `path` | string | *required* |  |
| `spacing` | array of number | `None` | Target voxel spacing in mm, e.g. [1, 1, 1] (or one value for isotropic) |
| `reference` | string | `None` | Resample onto the grid of this image (size, spacing, origin, direction) |
| `factor` | number | `None` | Upsample (>1) or downsample (<1) isotropically by this factor |
| `interpolation` | `linear` \| `nearest` \| `bspline` | `linear` |  |
| `is_mask` | boolean | `False` | Use nearest-neighbour interpolation and preserve labels |
| `output` | string | `None` |  |

### `reorient_image`

Re-order/flip the axes of a 3D image (or mask) to a standard orientation code.

| parameter | type | default | description |
|---|---|---|---|
| `path` | string | *required* |  |
| `orientation` | string | `RAS` | Target axis code such as RAS, LPS, LPI, RAI |
| `is_mask` | boolean | `False` |  |
| `output` | string | `None` |  |

### `crop_image`

Crop an image (and optionally masks) to a box or to a mask's bounding box. Geometry is
        preserved so cropped results stay aligned with the original in physical space.

| parameter | type | default | description |
|---|---|---|---|
| `path` | string | *required* |  |
| `box_xyz` | array of integer | `None` | Inclusive native box [x0, y0, z0, x1, y1, z1] (2D: [x0, y0, x1, y1]) |
| `mask` | string | `None` | Crop to the bounding box of this mask instead of box_xyz |
| `margin` | integer | `5` | Extra voxels around the box |
| `also` | array of string | `None` | Masks to crop with the same box (saved next to the output) |
| `output` | string | `None` |  |

### `n4_bias_correction`

N4 bias field correction for MRI (removes low-frequency intensity inhomogeneity).

| parameter | type | default | description |
|---|---|---|---|
| `path` | string | *required* |  |
| `mask` | string | `None` | Foreground mask (default: Otsu) |
| `shrink` | integer | `4` | Shrink factor for speed (4 = fast, 1 = full resolution) |
| `output` | string | `None` |  |
| `save_bias_field` | boolean | `False` |  |

### `register_images`

Register the moving image to the fixed image (rigid/affine/deformable), save the
        transform (.tfm), the warped image and optionally warped masks; returns a checkerboard-style
        overlay preview (fixed = gray, warped moving = red contour of its Otsu foreground).

| parameter | type | default | description |
|---|---|---|---|
| `fixed` | string | *required* | Reference image (stays fixed) |
| `moving` | string | *required* | Image to align to the fixed image |
| `transform` | `rigid` \| `affine` \| `bspline` | `rigid` |  |
| `metric` | `mattes` \| `correlation` \| `meansquares` | `mattes` | mattes = mutual information (multi-modal), correlation/meansquares for same modality |
| `iterations` | integer | `200` |  |
| `sampling` | number | `0.2` | Fraction of voxels sampled for the metric |
| `moving_masks` | array of string | `None` | Masks in the moving space to warp with the same transform |
| `output` | string | `None` | Warped moving image path |
| `preview` | boolean | `True` |  |

### `apply_transform`

Apply a saved transform to another image or mask (e.g. propagate a baseline mask to a follow-up).

| parameter | type | default | description |
|---|---|---|---|
| `transform_file` | string | *required* | .tfm file written by register_images |
| `moving` | string | *required* |  |
| `reference` | string | *required* | Image defining the output grid (the fixed image) |
| `is_mask` | boolean | `False` |  |
| `interpolation` | `linear` \| `nearest` \| `bspline` | `linear` |  |
| `output` | string | `None` |  |

### `combine_masks`

Merge several masks into one (e.g. lobes -> lung, organ minus lesion, stack organs as labels).

| parameter | type | default | description |
|---|---|---|---|
| `masks` | array of string | *required* | Label maps with identical geometry |
| `mode` | `union` \| `intersection` \| `subtract` \| `label` | `union` | union/intersection/subtract on foreground (binary result); label = mask i becomes label i+1 |
| `names` | array of string | `None` | label mode: names for the labels |
| `output` | string | `None` |  |

### `mask_features`

Radiomics-style shape features (volume, surface area, sphericity, elongation, flatness,
        PCA axes, max extent) and first-order intensity statistics (percentiles, skewness, kurtosis,
        entropy) per label. Dependency-free; for full texture radiomics use pyradiomics on the same files.

| parameter | type | default | description |
|---|---|---|---|
| `mask` | string | *required* |  |
| `image` | string | `None` | Image for first-order intensity features |
| `labels` | array of integer | `None` | Label ids (default: every label present) |

*Read-only.*

### `mask_to_mesh`

Export a surface mesh (STL/OBJ, physical mm coordinates) for 3D printing or 3D viewers.

| parameter | type | default | description |
|---|---|---|---|
| `mask` | string | *required* |  |
| `label` | integer | `None` | Label to extract (default: all foreground) |
| `output` | string | `None` | .stl (binary) or .obj file |
| `step` | integer | `1` | Marching-cubes step size (larger = coarser mesh) |

| parameter | type | default | description |
|---|---|---|---|
| `folder` | string | *required* | Directory containing DICOM files (searched recursively) |
| `recursive` | boolean | `True` |  |

*Read-only.*

### `render_view`

Render the image (with masks and prompts) so you can look at it. Tick labels are native
        voxel coordinates. Use layout='three-plane' for orientation, 'montage' to check the whole
        stack, and crop_to_mask=True for detail.

| parameter | type | default | description |
|---|---|---|---|
| `image` | string | *required* |  |
| `masks` | array of string | `None` | Label maps to overlay (same geometry as the image) |
| `plane` | `axial` \| `coronal` \| `sagittal` | `axial` |  |
| `layout` | `single` \| `three-plane` \| `montage` | `single` | single slice, three orthogonal planes, or a montage of several slices |
| `slices` | array of integer | `None` | Slice indices (native, along `plane`); default: largest mask area or the middle |
| `n_slices` | integer | `9` | montage: number of slices spread over the mask extent |
| `window` | any | `None` | Preset (soft-tissue, lung, bone, brain, liver ...), {center,width}, [lower, upper] or 'auto' |
| `mode` | `fill` \| `contour` \| `both` | `both` | How to draw masks |
| `alpha` | number | `0.35` |  |
| `labels` | array of integer | `None` | Only draw these label ids |
| `colors` | array of string | `None` | Hex colour per mask file (default: palette per label) |
| `prompts` | array of Prompt | `None` | Draw these prompts (to verify placement before segmenting) |
| `grid` | boolean | `True` | Tick labels in native voxel coordinates |
| `crop_to_mask` | boolean | `False` | Zoom to the mask bounding box |
| `center_xyz` | array of number | `None` | three-plane: crossing point (native voxels) |
| `title` | string | `None` |  |
| `max_px` | integer | `900` |  |
| `renderer` | string | `png` | Renderer name: png (default) or html, or a plugin |
| `output` | string | `None` | Save the figure here (default: omm_outputs/views/...) |

*Read-only.*

## Prompts (guidelines)

| prompt | description |
|---|---|
| `batch-processing` | Run a model over many images with run_batch, sample cases for visual QC, handle failures, and deliver a CSV plus a short QC report. |
| `brain-mri-preprocessing` | Standard brain MRI preparation - check orientation, N4 bias correction, skull stripping with HD-BET or SynthStrip, QC of the brain mask, and hand-off to downstream models. |
| `chest-xray-triage` | Classify a chest X-ray with TorchXRayVision, sanity-check the image, report calibrated probabilities honestly, and segment a finding with a box prompt when localisation is needed. |
| `compare-two-segmentations` | Compare a prediction against a reference (or two methods against each other) with overlap and surface metrics and a visual difference map. |
| `getting-started` | Orientation for agents - what the tools are, the coordinate conventions, and the standard loop (inspect -> segment -> look -> refine -> measure -> report). |
| `lung-ct-analysis` | Quantitative lung CT - lungmask lungs/lobes, per-lobe volumes, LAA% emphysema index, optional vessel/airway masks with TotalSegmentator, and a montage QC. |
| `multi-organ-ct-report` | Produce a volumetry table for several organs from one CT with TotalSegmentator, with per-organ QC figures and a Markdown/HTML report. |
| `qc-checklist` | The minimum set of checks before a mask is accepted - visual, geometric, intensity and consistency checks with concrete tool calls. |
| `registration-followup` | Align a follow-up scan to a baseline (rigid/affine/deformable), propagate the baseline mask, re-segment on the follow-up, and report volume change with a visual check. |
| `segmentation-2d-prompted` | Protocol for 2D images (X-ray, ultrasound frame, dermoscopy, endoscopy, histology tile, single slice) with SAM 2 / MedSAM2 - place prompts, verify, refine with negative points. |
| `segmentation-3d-ct` | End-to-end protocol for 3D CT segmentation - inspect, choose automatic (TotalSegmentator) vs promptable (MedSAM2) models, QC in three planes, measure volume, report. |
| `segmentation-3d-mri` | MRI-specific notes - intensity is not calibrated, choose windows from percentiles, prefer MedSAM2 with boxes or TotalSegmentator total_mr, QC per sequence. |

Every prompt accepts optional `image` and `goal` arguments.
